## 📌 Ringkasan Proyek
**KawanTumbuh** adalah platform web edukasi kesehatan (*Edu-Health*) responsif yang dirancang untuk mendemokratisasi deteksi dini tumbuh kembang balita (*Golden Age* 0–6 tahun) dan pendampingan anak berkebutuhan khusus (ABK: *speech delay*, autisme, ADHD, gangguan motorik).

KawanTumbuh memadukan **Skrining Mandiri Visual Bergambar (tanpa istilah medis rumit)**, **Panduan Stimulasi Bermain Harian di Rumah (*Home-Therapy Playbook*)**, serta **Dukungan Asisten Suara (*Voice Guidance*)** yang ramah bagi orang tua berliterasi rendah dan pengasuh lansia di desa.
