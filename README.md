## 📌 Ringkasan Proyek
**AksesWarga** adalah platform web responsif berbasis navigasi dan direktori fasilitas publik inklusif yang dirancang untuk mendukung mobilitas mandiri harian bagi penyandang disabilitas fisik (kursi roda), disabilitas sensorik (tunanetra), lansia, dan ibu membawa balita. 

AksesWarga menggabungkan pemetaan rute bebas hambatan, direktori aksesibilitas fasilitas publik (faskes, transportasi, pasar), serta fitur pelaporan hambatan trotoar berbasis suara (*voice-first*) yang ramah bagi masyarakat berliterasi digital rendah.
